## ✨ Key Features

1. **Lalithaa Jewellery Inspired Luxury Aesthetic**:
   - Royal crimson/maroon and champagne gold luxury design system.
   - Elegant typography with Google Fonts (*Cinzel*, *Playfair Display*, and *Plus Jakarta Sans*).
   - Responsive design for mobile, tablet, and desktop with sticky mobile action bar.

2. **Daily Bullion Rate Marquee (Live Rates Ticker)**:
   - Header ticker displaying live market rates for:
     - 22K Gold (916 BIS Hallmarked)
     - 24K Pure 999 Gold
     - Pure Silver
   - Rates can be dynamically updated via the Admin Dashboard.

3. **Curated Product Collections with Real-Time Filters**:
   - Proposed Categories:
     - **Gold jewellery**
     - **Chains and necklaces**
     - **Earrings and bangles**
     - **Bridal jewellery and rings**
   - Instant search keyword filter and sorting (Price, Net Weight, Featured).
   - **Quick View Modal** detailing gross weight in grams, purity, and lowest making charges / value addition (V.A.).

4. **11-Month Gold Savings Scheme (Chit Plan) Calculator**:
   - Interactive monthly slider from ₹1,000 to ₹50,000/month.
   - Real-time calculation of total contributions, **1-month free bonus contribution by Jain Jewellers**, estimated 22K gold grams, and 0% making charge benefits upon maturity.

5. **WhatsApp & Phone Direct Enquiries**:
   - Instant click-to-call and pre-formatted WhatsApp chat enquiry buttons for each jewellery design.

6. **Admin Dashboard (`#admin`)**:
   - Add, edit, and remove products with custom photos, weights, purity, prices, and stock status.
   - Update daily gold rates.
   - View customer enquiries and leads with one-click WhatsApp reply.
   - Toggle the owner verification disclaimer banner.

## 🚀 Getting Started

### 1. View Directly in Browser
Simply open `index.html` in any web browser.

### 2. Run with Node.js Server
```bash
node server.js
```
The application will be served at `http://localhost:8080/`.
